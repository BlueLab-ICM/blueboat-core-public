| Topic | Type | Publisher | Meaning |
| --- | --- | --- | --- |
| `/frontseat/gps` | `sensor_msgs/NavSatFix` | gateway | Position, 5 Hz |
| `/frontseat/heading` | `std_msgs/Float64` | gateway | Degrees from north |
| `/frontseat/speed` | `std_msgs/Float64` | gateway | Ground speed, m/s |
| `/frontseat/yaw_rate` | `std_msgs/Float64` | gateway | rad/s |
| `/frontseat/mode` | `std_msgs/String` | gateway | ArduPilot mode |
| `/frontseat/battery` | `sensor_msgs/BatteryState` | gateway | |
| `/frontseat/temperature` | `sensor_msgs/Temperature` | gateway | |
| `/frontseat/thruster_pwm` | `std_msgs/Int32MultiArray` | gateway | Servo outputs, µs |
| `/frontseat/home` | `sensor_msgs/NavSatFix` | gateway | Autopilot home, latched |
| `/frontseat/failsafe` | `std_msgs/String` | gateway | Link-loss parameters, latched |
| `/frontseat/time` | `sensor_msgs/TimeReference` | gateway | GPS time against the backseat clock |
| `/frontseat/params` | `std_msgs/String` | gateway | Parameter snapshot, latched |
| `/frontseat/set_home` | `sensor_msgs/NavSatFix` | executive | Sets the autopilot home |
| `/helm/setpoint` | `core_interfaces/Setpoint` | executive, skills | Motion requests |
| `/helm/grant` | `core_interfaces/HelmGrant` | executive | Who may drive, 10 Hz |
| `/helm/output` | `core_interfaces/Setpoint` | helm | The one command |
| `/helm/status` | `core_interfaces/HelmStatus` | helm | Latched |
| `/helm/engage` | `core_interfaces/Engage` (service) | helm | Start or end an engagement |
| `/fleet/peers` | `core_interfaces/PeerState` | fleet | Other vehicles |
| `/executive/request` | `std_msgs/String` | console | JSON commands |
| `/executive/status` | `std_msgs/String` | executive | JSON, latched |
| `/skills/<name>` | `core_interfaces/RunSkill` (action) | skill | |
| `/events` | `diagnostic_msgs/DiagnosticArray` | any | One event per message |
| `/diagnostics` | `diagnostic_msgs/DiagnosticArray` | any | Health, 1 Hz |
| `/system/health` | `diagnostic_msgs/DiagnosticArray` | recorder | All modules, latched |
| `/backseat/temperature` | `sensor_msgs/Temperature` | monitor | |
| `/ops/container_stats` | `std_msgs/String` | monitor | CSV |

Modules add `/sensors/*`, `/perception/*` and `/skills/<name>/*`. `/sim/*` exists only in simulation.
