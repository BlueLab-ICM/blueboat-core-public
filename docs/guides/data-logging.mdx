title: "Mission data"
description: "What a mission records, and where."
---

`start-mission.sh` creates one folder per mission under `$DEPLOY_DATA_ROOT`.

```
<YYYYMMDD_HHMMSS>_<name>/
  manifest.yaml     mission id, boot id, code versions, image ids, start and end
  verify.json       result of the mission check
  config/           configuration used, and a diff of any uncommitted code
  rosbags/          MCAP, split every recording.split_seconds
  experiment_logs/
    events.jsonl    what happened and why, synced to disk on every line
    telemetry.jsonl 5 Hz summary
    autopilot_params.json   ArduPilot parameters at start
    executive/<run>/        plan, events, results, detections, frames
  system/           container logs
  <module>/         a module's own files
```

## Four streams

| Stream | Job | Store |
| --- | --- | --- |
| Events | What happened and why | `events.jsonl` |
| Telemetry | Numbers | MCAP and `telemetry.jsonl` |
| Text logs | Debugging, never parsed | journald, copied to `system/` |
| Health | Is it working now | `/diagnostics`, summed up on `/system/health` |

Events reach the log from three places: `/events` from any node, `/rosout` at WARN and above, and health changes. A module reports both with `ModuleHealth`. A repeated log line passes once per 30 s, with a count.

## Time

Every event has `t_mono`, `t_system`, and `t_utc` once the autopilot has GPS time. The recorder logs a `clock` event with the offset between the backseat clock and GPS every minute, so logged times can always be corrected.

## After a crash or a power cut

Docker logs go to journald, tagged with the mission id, so they survive the container and the power cut. The next `start-mission.sh` finds the open mission, saves its logs, reindexes any bag left open, checks it and files it. Only the file being written at the cut is at risk.

## Mission check

`scripts/data/mission-verify.py <mission>` runs at the end of every mission. It reports an unclean end, uncommitted code, missing topics, bad GPS, telemetry gaps, clock offset, errors and collision overrides.
